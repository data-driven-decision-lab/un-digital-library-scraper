LibSQL Python client pattern:
```python

def get_turso_connection():
    url = os.getenv("TURSO_DATABASE_URL")
    auth_token = os.getenv("TURSO_AUTH_TOKEN")
    return libsql.connect(url, auth_token=auth_token)
```

Execute query:
```python
conn = get_turso_connection()
rows = conn.execute("SELECT * FROM table").fetchall()
# rows is list of tuples; use column names from cursor.description
```

Upsert pattern (LibSQL = SQLite):
```python
conn.executemany(
    "INSERT OR REPLACE INTO table_name (col1, col2, ...) VALUES (?, ?, ...)",
    list_of_tuples
)
conn.commit()
```
