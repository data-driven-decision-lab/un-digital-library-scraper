<objective>
Three independent fixes to dashboard_data_pipeline.py:
1. PIPE-03: Exclude zero-vote countries from ALL three output tables:
   - generate_annual_scores(): drop rows where Total Votes in Year == 0 (AFG/VEN have no pillar
     scores and appear only as noise in the annual_scores table).
   - generate_similarity_matrix(): filter out all-zero vote vectors (active_cols) so AFG/VEN
     are absent from pairwise_similarity_yearly.
   - generate_topic_votes(): zero-vote countries are already excluded by the existing
     .isin(['YES','NO','ABSTAIN']) filter — no code change needed, but a verify assertion
     must confirm this.
2. PIPE-04 + PIPE-05: Remove round(x, 4) precision truncation and the abs(x) > 1e3 guard
   from save_data_to_turso() for float score columns.
3. PIPE-06: Add an inline comment in generate_annual_scores() documenting that Pillar X Score
   columns contain normalized (0-100 min-max) values, not raw scores.

Purpose: These fixes close the remaining data quality gaps — country-set inconsistency across
ALL three output tables, precision loss on CosineSimilarity, silent nullification of valid
scores, and a misleading column name that confuses downstream analysis.

Output: Three targeted edits to dashboard_data_pipeline.py. After a pipeline re-run,
zero-vote countries (AFG, VEN) will be absent from annual_scores, topic_votes_yearly, and
pairwise_similarity_yearly.
</objective>
