    **# UN Digital Library Scraper**

    One-paragraph overview: Pipeline for scraping, classifying, and analyzing UN General Assembly voting data. Stores data in Turso (LibSQL). Exposes analytics via a FastAPI REST API deployed to Google Cloud Run.

    **## Architecture**

    Brief layered description:
    1. **Scraper Pipeline** (`src/un_data_pipeline/scraper_pipeline.py`) — Selenium scrapes UN Digital Library, OpenAI GPT-4o-mini classifies resolutions with UNBIS tags and geo-tags, data written to Turso `un_votes_raw` and `un_votes_with_sc` tables.
    2. **Dashboard Pipeline** (`src/un_data_pipeline/dashboard_data_pipeline.py`) — Reads `un_votes_with_sc`, computes Pillar 1/2/3 scores and pairwise similarity, writes results to Turso (`annual_scores`, `topic_votes_yearly`, `pairwise_similarity_yearly`) and saves CSV copies to `src/un_report_api/app/required_csvs/` for API fallback.
    3. **REST API** (`src/un_report_api/app/main.py`) — FastAPI serving country reports, rankings, and Security Council analysis. Reads from Turso tables and CSV fallbacks.

    Data flow one-liner: `UN Digital Library → scraper → Turso → dashboard pipeline → Turso + CSVs → API → clients`

    Cross-references: `See docs/METHODOLOGY.md for pillar score formulas. See docs/SCHEMA.md for database table reference.`

    **## Requirements**

    - Python 3.11+
    - Chrome browser (for Selenium scraper)
    - Turso account with a database created
    - OpenAI API key (for scraper classification)
    - Google Cloud project (for deployment)

    **## Local Setup**

    ```bash
    # Clone repository
    git clone https://github.com/data-driven-decision-lab/un-digital-library-scraper.git
    cd un-digital-library-scraper

    # Create and activate virtual environment
    python -m venv venv
    source venv/bin/activate  # Windows: venv\Scripts\activate

    # Install dependencies
    pip install -r requirements.txt

    # Configure environment variables
    cp .env.example .env
    # Edit .env and fill in:
    #   TURSO_DATABASE_URL  — from Turso dashboard (libsql://...)
    #   TURSO_AUTH_TOKEN    — from Turso dashboard
    #   API_KEY             — OpenAI API key
    ```

    **Initialise the database schema:**

    ```bash
    # Apply schema to your Turso database
    cat db/schema.sql | turso db shell <your-database-name>
    ```

    **## Running the Pipelines**

    ```bash
    # 1. Run the scraper (fetches new UN resolutions and writes to Turso)
    python -c "import sys; sys.path.insert(0, 'src'); from un_data_pipeline.scraper_pipeline import main; main()"

    # 2. Run the dashboard scoring pipeline (reads Turso, computes scores, writes back to Turso)
    python -m src.un_data_pipeline.dashboard_data_pipeline
    ```

    Note: The scraper requires Chrome and network access to digitallibrary.un.org. Pipeline runs are logged to the `pipeline_runs` Turso table.

    **## Running the API Locally**

    ```bash
    cd src/un_report_api/app
    uvicorn main:app --host 0.0.0.0 --port 8000 --reload
    ```

    API documentation available at `http://localhost:8000/docs` (Swagger UI).

    **## Deployment (Google Cloud Run)**

    Deployment is automated via Cloud Build on push to main. The `cloudbuild.yaml` pipeline:
    1. Builds Docker image tagged with commit SHA
    2. Pushes to Google Container Registry (`gcr.io/$PROJECT_ID/unreportapi`)
    3. Deploys to Cloud Run service `unreportapi` in `europe-west1`

    **Required Cloud Build configuration:**
    - Set `TURSO_DATABASE_URL` and `TURSO_AUTH_TOKEN` as substitution variables or Secret Manager secrets in your Cloud Build trigger.

    **Manual deploy:**
    ```bash
    # Build and push image
    docker build -t gcr.io/YOUR_PROJECT_ID/unreportapi:latest .
    docker push gcr.io/YOUR_PROJECT_ID/unreportapi:latest

    # Deploy to Cloud Run
    gcloud run deploy unreportapi \
      --image gcr.io/YOUR_PROJECT_ID/unreportapi:latest \
      --region europe-west1 \
      --platform managed \
      --allow-unauthenticated \
      --set-env-vars TURSO_DATABASE_URL=your_url,TURSO_AUTH_TOKEN=your_token
    ```
